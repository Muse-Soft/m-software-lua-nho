# Lửa Nhỏ — Tiệm nến thơm thủ công

Lửa Nhỏ là tiệm nến thơm thủ công: mỗi hũ nến được đổ tay, ủ hương và thắp thử trước khi giao. Trang web giới thiệu bộ sưu tập nến theo nhóm mùi, quy trình đổ nến thủ công, bảng giá, câu chuyện thương hiệu và form đặt hàng / đặt lịch workshop.

> Lưu ý: đây là bản demo — giá, đánh giá và một số thông tin trên trang là dữ liệu mẫu. Địa chỉ, điện thoại và thông tin liên hệ thật đang chờ bổ sung.
